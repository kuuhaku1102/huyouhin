## 概要

このテーマは、不用品回収業者の情報を管理し、ユーザーに最適な業者を紹介するためのプラットフォームです。ランキング機能、一括見積もりフォーム、カテゴリ別検索など、アフィリエイトサイトに必要な機能を網羅しています。

### デザインコンセプト

**エレガントで完璧なスタイル（A elegant and perfect style）**を採用し、ビジネスライクでありながらおしゃれな印象を実現しています。

- **フォント**: Playfair Display（見出し）+ Inter（本文）
- **カラー**: プロフェッショナルなブルー系グラデーション
- **レイアウト**: カード型デザイン、滑らかなアニメーション
- **レスポンシブ**: モバイル・タブレット・デスクトップ完全対応

## セットアップ

### 前提条件

- WordPress 5.0以上
- PHP 7.4以上
- MySQL 5.7以上

### インストール手順

1. **テーマのアップロード**
   ```bash
   # GitHubからクローン
   git clone https://github.com/kuuhaku1102/huyouhin.git
   
   # WordPressのテーマディレクトリにコピー
   cp -r huyouhin /path/to/wordpress/wp-content/themes/
   ```

2. **テーマの有効化**
   - WordPress管理画面 → 外観 → テーマ
   - 「不用品回収比較センター」を有効化

3. **固定ページの作成**
   
   以下の固定ページを作成し、対応するテンプレートを選択してください。

   | ページ名 | スラッグ | テンプレート |
   |----------|----------|--------------|
   | ランキング | `rankings` | Rankings Page |
   | 見積もり | `quote` | Quote Form Page |

4. **メニュー設定**
   - 外観 → メニュー → 新規メニュー作成
   - 作成した固定ページを追加
   - 「メインメニュー」として設定

5. **パーマリンク設定**
   - 設定 → パーマリンク設定
   - 「投稿名」を選択して保存

## 使い方

### 業者情報の登録

1. 管理画面 → 業者情報 → 新規追加
2. 以下の情報を入力:
   - **タイトル**: 業者名
   - **本文**: 業者の説明文
   - **アイキャッチ画像**: 業者のロゴまたは写真
   - **カスタムフィールド**:
     - 評価（1-5）
     - 料金帯（例: 10,000円〜50,000円）
     - 電話番号
     - メールアドレス
     - ウェブサイト
     - 対応エリア（カンマ区切り）
     - ランキング順位
     - ランキングカテゴリ

### ランキングの管理

1. 管理画面 → 業者情報 → **ランキング管理**
2. 上部のタブでカテゴリを選択:
   - 総合ランキング
   - 料金が安い
   - 対応が早い
   - サービス品質
3. **ドラッグ&ドロップで順位変更**:
   - 左側の「現在のランキング」内で業者をドラッグして順位変更
   - 右側の「未ランクの業者」から左側にドラッグして追加
   - 左側から右側にドラッグしてランキングから除外
4. 「ランキングを保存」ボタンをクリック

### 見積もり依頼の確認

1. 管理画面 → 見積もり依頼
2. 各依頼をクリックして詳細を確認
3. ステータスを変更:
   - 未対応
   - 連絡済み
   - 完了
   - キャンセル

### コラムの作成

1. 管理画面 → コラム → 新規追加
2. SEO対策を意識したコンテンツを作成:
   - 「不用品処分の方法」
   - 「粗大ゴミの捨て方」
   - 「遺品整理のポイント」など

## カスタマイズ

### デザインのカスタマイズ

デザインシステムは `style.css` の CSS変数で管理されています。

```css
:root {
  /* カラー */
  --color-primary: #1e40af;        /* メインカラー */
  --color-accent: #f59e0b;         /* アクセントカラー */
  --color-text: #1e293b;           /* テキストカラー */
  
  /* フォント */
  --font-heading: 'Playfair Display', serif;
  --font-body: 'Inter', sans-serif;
  
  /* スペーシング */
  --spacing-sm: 1rem;
  --spacing-md: 1.5rem;
  --spacing-lg: 2rem;
}
```

これらの変数を変更することで、サイト全体の配色やスペーシングを統一的に調整できます。

### 新しいテンプレートの追加

1. テーマディレクトリに新しいPHPファイルを作成
2. ファイルの先頭にテンプレート名を記述:
   ```php
   <?php
   /**
    * Template Name: カスタムページ名
    */
   get_header();
   ?>
   
   <!-- ページコンテンツ -->
   
   <?php get_footer(); ?>
   ```

### カスタム投稿タイプの追加

`functions.php` の `fuyohin_register_post_types()` 関数内に追加:

```php
register_post_type('custom_type', array(
    'labels' => array(
        'name' => 'カスタムタイプ',
        'singular_name' => 'カスタム',
    ),
    'public' => true,
    'has_archive' => true,
    'supports' => array('title', 'editor', 'thumbnail'),
));
```

### 主要ファイルの説明

#### `functions.php`
テーマの中核となるファイルです。以下の機能を実装しています:

- **カスタム投稿タイプ**: 業者情報、見積もり依頼、コラム、口コミ
- **カスタムフィールド**: 業者の詳細情報、ランキング情報
- **Ajax処理**: 見積もりフォームの送信処理
- **管理画面**: ランキング管理ページ
- **テーマサポート**: アイキャッチ画像、カスタムロゴ、メニュー

#### `style.css`
エレガントなデザインシステムを実装:

- CSS変数によるデザイントークン管理
- レスポンシブデザイン（モバイルファースト）
- カード型レイアウト
- 滑らかなアニメーション効果

#### テンプレートファイル
各ページの表示を制御:

- `front-page.php`: トップページ（ヒーロー、特徴、トップ3ランキング）
- `page-rankings.php`: ランキングページ（カテゴリ別タブ表示）
- `page-quote.php`: 見積もりフォーム（3ステップ、Ajax送信）

## よくある質問（FAQ）

### Q1: ランキングが表示されない

**A:** 以下を確認してください:
1. 業者情報が登録されているか
2. ランキング管理画面で順位が設定されているか
3. ランキングカテゴリが正しく設定されているか

### Q2: 見積もりフォームが送信できない

**A:** 以下を確認してください:
1. WordPressのAjax機能が有効か
2. ブラウザのコンソールにエラーが表示されていないか
3. `functions.php` の `fuyohin_handle_quote_form()` が正しく動作しているか

### Q3: デザインが崩れる

**A:** 以下を確認してください:
1. `style.css` が正しく読み込まれているか
2. 他のプラグインとのCSSの競合がないか
3. ブラウザのキャッシュをクリアしてみる

### Q4: ランキングのドラッグ&ドロップが動作しない

**A:** 以下を確認してください:
1. jQuery UIが正しく読み込まれているか
2. ブラウザのJavaScriptが有効になっているか
3. 管理画面でJavaScriptエラーが発生していないか
